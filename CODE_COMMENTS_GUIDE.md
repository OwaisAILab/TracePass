# TracePass Code Commenting Guide

This copy of TracePass is intentionally commented for presentation, viva, maintenance, and learning purposes.

## Comment convention

- **Python:** module notes, class/function explanations, and database-field explanations are placed near the code they describe.
- **Flask routes:** comments explain what the route receives, validates, changes, and returns.
- **Models:** database fields and relationships are identified so the database design can be explained easily.
- **Templates:** Jinja conditions/loops, forms, tables, navigation, and scripts have comments explaining their purpose.
- **JavaScript:** event handlers and DOM operations are identified as client-side behavior.
- **CSS:** selector blocks are labelled with the UI element they style.

The comments are explanatory only; they are not intended to replace the code or application documentation. Existing business logic has been preserved.
